# Lumière Beauty — сайт салона красоты

Адаптивный учебный сайт на основе предоставленного index.html. Сохранены оформление, услуги, цены в тенге и демонстрация записи и оплаты. Не требует установки библиотек или сборки.

## Просмотр
Откройте index.html в браузере.

## Публикация на GitHub Pages
1. Создайте репозиторий beauty-salon в своём аккаунте GitHub. Для бесплатного аккаунта используйте публичный репозиторий.
2. Загрузите содержимое этой папки в корень репозитория: index.html, .nojekyll и README.md. Архив ZIP загружать вместо файлов не нужно.
3. В репозитории откройте Settings → Pages.
4. В Source выберите Deploy from a branch, затем ветку main и папку /(root). Нажмите Save.
5. После завершения публикации ссылка появится в разделе Pages.

Официальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Что изменить для своего салона
В index.html замените название Lumière Beauty, описания услуг, город и цены. Цены есть и в HTML, и в объекте services внутри script: меняйте оба места.

## Возможности и ограничения
- Четыре услуги, переход от карточки к форме, расчёт суммы, выбор даты и времени.
- Подтверждение демонстрационной оплаты формируется в браузере.
- Заявки никуда не отправляются и не сохраняются после перезагрузки страницы.
- Реальных платежей и бронирования нет. Для рабочего салона потребуется подключение сервиса записи и платёжного провайдера.

Репозиторий и публикация в аккаунте GitHub не создаются этим архивом автоматически.
